FILMS FOR THE HALL OF FAME
==========================

Drop each film into this folder with exactly the file name below (MP4, H.264 video
with AAC audio plays best in Microsoft Edge). The kiosk finds them on its next
start: "Coming soon" disappears and the film plays. No code change is needed.

intro.mp4     Welcome to the Hall of Fame (Introduction)
              Also loops silently behind the welcome screen.
birth.mp4     The birth of an Air Force (1961 – 1964 · Retrospective)
war.mp4       Wings over the war (1967 – 1970 · Retrospective)
hercules.mp4  Hercules: keeping the fleet flying (C-130 maintenance, 2011)
sixty.mp4     Sixty years (Official anniversary, 2024)
jaji.mp4      Jaji: the College (Graduation, 2014)
lineage.mp4   Chiefs of the Air Staff: a lineage (1963 – today)

To rename a file or add a film, edit the films list in data/content.js.
GitHub rejects single files over 100 MB; copy large films to the kiosk directly
or use Git LFS.
